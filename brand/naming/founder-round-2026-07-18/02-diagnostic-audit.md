# Diagnostic construction audit

> Internal record. Do not use this context while giving the first founder reaction.

The blind set samples the main forms that repeatedly appeared in the historical corpus. Its purpose is taste diagnosis, not candidate selection.

| Form family | Representative names |
|---|---|
| Familiar words / stance words | Bearing, Leeway, Actual, Upright, Restraint, Byline, Contrarywise |
| Recognizable constructions | Rangekind, Yearproof, Stillself, Nextkeeping, Showthrough, Layerwork |
| Category-linked constructions | Skinspect, Skinprint, Good at Skin, Made for This Face, Surface Finish |
| Authentic technical or cultural terms | Ricercar, Plumb, Vernier, Fascicle, Allostasis, Caliper |
| Tension compounds / propositions | Better Trouble, Goldseam, Candid Standard, Standard of One |
| Spoken statements / phrases | No Mystery, Sure Enough |
| Invented house forms | Anvorel, Calvere, Hollismere, Elvenne |

The set deliberately includes forms the founder is expected to dislike. A useful diagnostic must establish negative boundaries, not quietly behave like another shortlist.
